# ISO/IEC 27001:2022

This folder will contain portfolio examples related to an Information Security Management System (ISMS).

## Planned contents

- `risk-assessment/` — risk register and risk-treatment examples.
- `statement-of-applicability/` — SoA template and applicability rationale.
- `policies/` — sample security policies.
- `control-implementation/` — control design and implementation notes.
- `evidence/` — evidence register and fictional evidence descriptions.

Examples will be clearly labeled as illustrative and will not reproduce copyrighted standard text.
