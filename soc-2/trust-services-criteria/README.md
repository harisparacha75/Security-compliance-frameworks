# SOC 2 Trust Services Criteria

## Purpose

This directory documents the Trust Services Criteria (TSC) used to organize the SOC 2 compliance portfolio.

## Scope

The portfolio focuses on the following criteria:

- **Security (Common Criteria):** Controls related to protecting systems and information against unauthorized access and other security threats.
- **Availability:** Controls related to maintaining system availability in accordance with defined comments.

## Control Mapping

The criteria are mapped to illustrative controls in the [SOC 2 Control Matrix](../control-matrix/control-matrix.csv).

## Status

This documentation is a work in progress. The criteria and mappings are illustrative and do not demonstrate compliance or audit readiness.

## Disclaimer

This is an educational portfolio project, not an audit report, attestation, or assurance opinion.
