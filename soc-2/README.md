# SOC 2

This folder contains illustrative SOC 2 control-documentation examples and a planning checklist with completion gates (not an assessment). The materials are for portfolio and learning purposes only and do not demonstrate SOC 2 compliance or audit readiness.

## Contents

- `trust-services-criteria/` — criteria notes and scope for the illustrative control matrix.
- `system-description.md` — starter system description template.
- `management-assertion-template.md` — unsigned assertion template.
- `control-matrix/` — illustrative control activities, owners, frequencies, and evidence for all 36 Security and Availability criteria.
- `policies/` — twelve draft policies covering security, access, incident response, change, vendors, continuity, vulnerabilities, logging, encryption, physical security, risk, and conduct.
- `evidence/` — evidence register and fictional evidence descriptions.
- `audit-readiness/` — planning checklist with completion gates (not an assessment); no readiness assessment has been performed.

SOC 2 is an examination and reporting framework. These materials are not an audit report or assurance opinion.
