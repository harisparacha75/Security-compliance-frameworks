# SOC 2

This folder contains illustrative SOC 2 control-documentation examples and an planning checklist with completion gates (not an assessment). The materials are for portfolio and learning purposes only and do not demonstrate SOC 2 compliance or audit readiness.

## Contents

- `trust-services-criteria/` — criteria notes and illustrative selected-control matrix.
- `system-description.md` — starter system description template.
- `management-assertion-template.md` — unsigned assertion template.
- `policies/change-management-policy.md` — draft change management policy.
- `control-matrix/` — sample control descriptions, owners, frequencies, and evidence.
- `policies/` — sample security policies.
- `evidence/` — evidence register and fictional evidence descriptions.
- `audit-readiness/` — planning checklist with completion gates (not an assessment); no readiness assessment has been performed.

SOC 2 is an examination and reporting framework. These materials are not an audit report or assurance opinion.
