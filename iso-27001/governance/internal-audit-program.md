# Internal Audit Program

**Status:** Draft template — no audit performed

## Program requirements

Define audit scope, criteria, frequency, methods, responsibilities, impartiality safeguards, reporting, and follow-up. Auditors should not audit their own work. Prioritize changes, risk, and prior results.
