# Logging and Monitoring Policy

**Document ID:** ISO-POL-006  
**Version:** 1.0  
**Status:** Draft — Portfolio Example  
**Owner:** SOC  
**Review Frequency:** Annually

## 1. Purpose

Define sample requirements for security logging, log protection, and monitoring activities.

## 2. Scope

Applies to in-scope systems and services that generate security-relevant events.

## 3. Requirements

- Identify and enable logging for security-relevant events based on risk and system capability.
- Protect logs against unauthorized access, modification, and deletion.
- Synchronize system clocks where feasible to support event correlation.
- Restrict access to logs to authorized personnel and retain logs according to documented business, legal, and contractual needs.
- Monitor relevant events, investigate alerts, and document response actions.
- Review logging coverage and alert rules periodically.

## 4. Roles and Exceptions

SOC coordinates monitoring and alert review; IT Operations supports log configuration. Exceptions must be documented and approved by an authorized owner.
