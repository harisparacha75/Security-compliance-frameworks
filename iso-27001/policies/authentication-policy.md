# Authentication Policy

**Document ID:** ISO-POL-005  
**Version:** 1.0  
**Status:** Draft — Portfolio Example  
**Owner:** IT Security  
**Review Frequency:** Annually

## 1. Purpose

Define requirements for protecting authentication information and using secure authentication mechanisms.

## 2. Scope

Applies to users, administrators, applications, and systems within the illustrative ISMS scope.

## 3. Requirements

- Use unique user identities where technically feasible.
- Require multi-factor authentication for privileged access and remote access where supported and appropriate to risk.
- Store and transmit passwords using approved secure mechanisms; never store passwords in plaintext.
- Protect authentication secrets, recovery codes, and tokens from unauthorized disclosure.
- Change or revoke credentials when compromise is suspected or access is no longer required.
- Review authentication configurations periodically and retain relevant records.

## 4. Roles and Exceptions

IT Security maintains this policy; system owners implement controls. Exceptions must be documented, risk-assessed, and approved by an authorized owner.
