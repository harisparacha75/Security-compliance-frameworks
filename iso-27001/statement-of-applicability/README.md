# Statement of Applicability (SoA)

## Purpose

The Statement of Applicability (SoA) documents the information
security controls selected for the Information Security
Management System (ISMS).

It records which controls are applicable, their implementation
status, the reasons for inclusion or exclusion, and the
associated evidence.

## Scope

This portfolio demonstrates a sample ISO/IEC 27001:2022
Statement of Applicability using illustrative control entries.

## SoA Register

The `soa-register.csv` file contains sample control entries
with the following fields:

- Control ID
- Control Name
- Applicability
- Justification
- Implementation Status
- Evidence Reference

## Implementation Status

The current entries are illustrative examples.
They do not represent a completed ISO 27001 audit or
certification.

Evidence references will be added as supporting documentation
