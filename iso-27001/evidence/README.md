# ISO 27001 Evidence Register

The evidence register contains planned, illustrative evidence references for each of the 76 applicable controls. IDs use the `ISO-EV-###` prefix to distinguish them from SOC 2 evidence IDs (`SOC2-EV-###`). `TBD` means no file has been collected or verified.

Evidence descriptions are examples only. Do not place confidential information, credentials, or personal data in this portfolio.
