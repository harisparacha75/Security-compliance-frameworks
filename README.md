# Security Compliance Frameworks

Practical, portfolio-focused documentation for **ISO/IEC 27001:2022** and **SOC 2**. This repository is designed to demonstrate how security controls can be documented, mapped, assessed, and supported with evidence.

> **Portfolio disclaimer:** Materials in this repository are illustrative working examples, not official standards, legal advice, audit opinions, or evidence of certification. Do not include confidential organizational information. ISO and AICPA standards may be copyrighted; this repository does not reproduce their full text.

## Objectives

- Document sample security controls and implementation approaches.
- Build risk assessment and evidence-tracking templates.
- Map related controls across ISO 27001 and SOC 2 without implying the frameworks are interchangeable.
- Demonstrate practical GRC and audit-readiness workflows.

## Frameworks covered

### ISO/IEC 27001:2022

Planned materials include an information-security risk register, a Statement of Applicability template, sample policy documents, control implementation notes, and an evidence register.

### SOC 2

Planned materials include a Trust Services Criteria mapping, a sample control matrix, evidence tracking, policy examples, and an audit-readiness checklist. SOC 2 is an examination and reporting framework, not an ISO-style certification.

## Planned workflow

1. Define a fictional organization and a clear scope for the examples.
2. Build the ISO 27001 risk register and control register.
3. Create the SOC 2 control matrix and evidence register.
4. Develop a cross-framework mapping with documented limitations.
5. Add sample evidence descriptions and review the materials for consistency.
