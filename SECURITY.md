# Security Policy

## Scope

This repository is an educational portfolio of fictional security and compliance documentation. It is not a production service.

## Reporting a Concern

If you identify a secret, personal data, or a potentially harmful configuration accidentally committed to this repository, do not publish it further. Contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile. Include the affected file path, commit or revision, and a brief description.

Do not include real credentials or sensitive data in public issues.

## Response

The maintainer should review reports, remove exposed secrets where appropriate, rotate credentials if any were exposed, and document remediation. No response-time guarantee is provided for this portfolio repository.
