# Cross-framework control mapping

This directory contains an illustrative crosswalk between ISO/IEC 27001:2022 (Annex A controls and, where no Annex A control fits, management-system clauses) and SOC 2 Trust Services Criteria. It covers all 36 Security and Availability criteria in the SOC 2 control matrix and lists each relationship in both directions. The crosswalk is a starting point for analysis, not a control equivalence claim.

- [ISO 27001–SOC 2 crosswalk](iso27001-soc2-crosswalk.csv)

Each relationship requires organization-specific validation of scope, control design, implementation, and evidence. A mapping does not establish compliance with either framework.
